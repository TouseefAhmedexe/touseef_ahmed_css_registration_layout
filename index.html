Notes for Interns

Scroll inside the box to read all the notes.

  • Save every file before you commit.
  • Run git status before every commit.
  • Use lowercase names without spaces for files and folders.
  • Test every link and form control in the browser.
  • Use DevTools to inspect an element when a style does not work.
  • Change one CSS value at a time and watch what happens.
  • Write commit messages that say what the commit adds.
